PCL-RS 运行说明
================

这是一个用 Rust 重写的 Minecraft 启动器（PCL 风格）。本包含命令行版本 pcl.exe。

快速开始
--------
1) 安装版本（默认 BMCLAPI CDN 加速，失败自动回退官方源）

   pcl.exe install 1.20.1

2) 启动游戏（缺失文件自动补全，离线账户直接开始）

   pcl.exe launch 1.20.1 --username Steve --memory 4096

3) 只想看会下载什么，不实际下载

   pcl.exe install 1.20.1 --dry-run

常用命令
--------
   pcl.exe list                     列出可安装版本
   pcl.exe list --installed         列出本机已安装版本
   pcl.exe info 1.20.1              版本详情（主类 / Java 要求 / 待下载体积）
   pcl.exe java                     列出本机 Java
   pcl.exe verify 1.20.1            校验完整性（SHA-1）
   pcl.exe account offline Steve    创建离线账户
   pcl.exe account ms               微软账户登录（设备码）
   pcl.exe mods search sodium --version 1.20.1 --loader fabric
   pcl.exe mods download sodium --version 1.20.1 --loader fabric

选项
----
   --dir <目录>     指定游戏目录（默认 %APPDATA%\.minecraft）
   --source cn      下载线路：cn = CDN 优先 / global = 官方优先 / official = 仅官方
   --dry-run        只打印计划或启动命令行
   --quiet          不显示进度条

说明
----
* 游戏本体与资源不随本包分发，运行时从官方源或授权 CDN 镜像下载。
* 微软登录需要自己的 Azure 应用 ID（公共客户端 + 启用设备代码流），
  通过环境变量 PCL_MS_CLIENT_ID 传入；本包不内置共享 client id。
* CurseForge 搜索/下载需要免费 API Key：
  设置环境变量 PCL_CURSEFORGE_KEY，或命令行 --api-key。
* 本机为 Intel HD 4000 / NVIDIA NVS 5400M（2012 年前后平台）。
  Minecraft 1.20+ 需要 OpenGL 3.2，若启动即崩溃（退出码 0xC0000005），
  先更新显卡驱动，或在 1.16.5 及更早版本上测试。
