陶瓦联机

            检测中…
          

          

            Terracotta 是一个独立的开源 Minecraft 联机工具（AGPL-3.0）。PCL-RS 不重新分发它的代码，
            只负责从官方 Release 下载、启动与关闭；建房间 / 加入房间在它自己的界面里完成。
          

          

            
            
            
            
          

          

            

            
          

          

        


        

          
使用步骤

          
    
            
  1. 点「一键下载并安装」，PCL-RS 会从官方 Release 取 Windows x64 版本并解压到游戏目录下的 pcl-rs/tools/terracotta/。
    2. 
            
  2. 点「启动」，在 Terracotta 界面里创建房间（房主）或输入房间码加入。
    3. 
            
  3. 回到主页启动 Minecraft，多人游戏里即可看到局域网房间。
    4. 
            
  4. 结束后可在本页点「停止」，或在 Terracotta 界面里退出。
    5.

关于 PCL-RS

          

            
版本0.1.0

            
仓库github.com/mc-githu/pcl-rs

            
许可GPL-3.0-or-later

          

          

            PCL-RS 是第三方独立实现，与 PCL 官方无关。下载走官方源与授权 CDN 镜像，Mod 走 Modrinth /
            CurseForge 官方 API，不附带、也不重新分发任何 Minecraft 游戏文件。
